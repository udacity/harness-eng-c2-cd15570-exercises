# Response Requirements

The customer-support response must satisfy all four criteria below.

## Deterministic criteria

1. The response contains exactly 100 words. Count words by splitting the response on whitespace.
2. The response includes the exact case ID shown in the customer case.

## Inferential criteria

3. The response follows the refund and replacement policy. It must not approve or promise a refund that the support agent is not authorized to provide.
4. The response gives the customer a useful, policy-compliant next step, such as accepting a replacement or requesting escalation to a billing specialist.
